# 🛡️ NetRat — Smart Network Traffic Analyzer

> 🚧 **Project Status: Under Development**

NetRat is a **Python-based network traffic analysis project** designed to capture, process, and analyze network traffic and eventually use **Machine Learning** to identify and classify different types of network activity.

The project is currently under active development, with the main focus on building a reliable pipeline for **packet capture → data processing → flow construction → feature preparation → ML-based traffic analysis**.

---

## 🎯 Project Goal

The goal of NetRat is to transform raw network traffic into meaningful information that can be used to understand and classify network activity.

---

## 🚧 Current Development

NetRat is being developed step-by-step.

### Current focus

- 📡 Network packet capture using **TShark**
- 🧹 Packet data cleaning and preprocessing
- 🗂️ Conversion of captured data into structured datasets
- 🔄 Bidirectional network flow construction
- 🔍 Flow validation and analysis
- 📊 Preparation of flow-level features for Machine Learning


> **Note:** Some planned features are not implemented yet as the project is still under development.
